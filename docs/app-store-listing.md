## Description [4000]
partymate is for the parties you're actually going to.

Hosts create a party and share an invite code. Guests join, say they're going, and see who else is coming. Like the people you want to meet. If they like you too, it's a match, and you can start chatting before the party.

- Invite-only: you only see parties you've been invited to. No feeds, no strangers.
- Private likes: people only find out you liked them if they like you back.
- Matches by party: see where you met, and which other parties you're both going to.
- Chat: real-time messages with read receipts.
- For hosts: share an invite code, see who's replied, and manage your guest list.
- Safety built in: report or block anyone, any time.
